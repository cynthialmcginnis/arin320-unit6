# ARIN 320 Unit 6: Domain-Specific AI Applications and Case Studies

Lecture slides for Unit 6 of ARIN 320, Artificial Intelligence Applications, University of Maryland Global Campus Asia.

## Files

| File | What it is |
|---|---|
| `index.html` | The full lecture: 83 slides, five cases, the simulations, the neural network, and the Fit Check |
| `short.html` | A 33-slide version for a 90-minute class |
| `hangman.html` | The Unit 6 AI Lab Sprint: two-player Hangman with AI terms from Units 0 to 6 |

## Keys

| Key | Action |
|---|---|
| Right arrow / Left arrow | Next and back |
| T | Big text for a small screen |
| P | Pick a student |
| S | Speaker notes |
| F | Full screen |
| Esc | See every slide |

The slides need an internet connection. They load Reveal.js, three.js, and TensorFlow.js from public CDNs.
